# Calcify Calculator

**Smart. Fast. Simple.**

Calcify is a modern, responsive web-based calculator application designed with a sleek and minimalist user interface. It features a seamless dark and light mode toggle, providing an optimal user experience across both desktop and mobile devices.

## About the Project

This project was built to demonstrate clean UI/UX design principles and core JavaScript logic without relying on any external libraries or frameworks. The focus was on creating a lightweight, fast, and highly functional calculator.

## Key Features

- **Theme Toggle:** Switch effortlessly between Dark Mode and Light Mode.
- **Core Operations:** Performs basic arithmetic operations including addition, subtraction, multiplication, and division.
- **Advanced Functions:** Includes percentage calculation and positive/negative value toggling.
- **Clear Function:** Instant "All Clear" (AC) button to reset the calculator state.
- **Responsive Design:** Fully optimized for all screen sizes, from mobile phones to large desktop monitors.
- **Modern UI:** Features rounded buttons, subtle hover effects, and a clean layout.

## Tech Stack

- **HTML5:** For semantic structure and layout.
- **CSS3:** For styling, flexbox/grid layout, and theme variables.
- **JavaScript (ES6+):** For calculator logic, DOM manipulation, and event handling.
